# Calculadora de Escalas

Web-app em HTML, CSS e JavaScript puros para calcular escalas de mapas, arquitetura e modelismo.

- **Real → Escala**, **Escala → Real** e **Descobrir escala**
- Medidas em altura (y), largura (x) e profundidade (z)
- Presets de cartografia, arquitetura, modelismo e ampliação, ou escala personalizada (`1:50.000`, `5:1`)
- Caixa 3D proporcional e comparação com objetos conhecidos
- Tema claro/escuro e histórico salvo no navegador

## Uso

Abra `index.html` no navegador. Não precisa de servidor nem de instalação.

## Testes

```
node test.js
```
